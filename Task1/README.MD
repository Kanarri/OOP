Показания счётчиков и начисления
Считает коммунальные начисления по лицевому счёту за месяц.

- Account -лицевой счёт, ключ равенства это номер
- Housing - помещение, площадь и число жителей
- Meter - счётчик, привязан к счёту и услуге, хранит показания
- MeterReadings - показание счётчика, дата и значение
- Tariff - тариф, действует на интервале от и до
- Norma - норматив потребления
- Charge - строка начисления в квитанции
- Receipt - квитанция за месяц с расшифровкой
- ServiceType - перечисление услуг с единицей измерения
- TarifZone - перечисление тарифных зон день и ночь
- InvalidReadingException - показание меньше предыдущего

Иерархия расчёта

ChargingRule (sealed интерфейс) с двумя реализациями:
ByMeterRule - начисление по показаниям счётчика
ByNormRule -начисление по нормативу
ChargingService выбирает правило по признаку ServiceType.isByMeter().

Все суммы в копейках, тип long. При делении используется целочисленное деление, округление вниз.
